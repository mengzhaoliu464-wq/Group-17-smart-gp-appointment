# Smart GP Appointment Management System – Diagram Source Files

PRT631 Information Systems Practice · Assignment IV Final Report · Darwin Group 17 · Charles Darwin University

This folder contains the diagrams used in the final report for the Smart GP Appointment Management System for Top End Medical Centre, Casuarina. Figure numbers match the report.

## How to view or edit

- **View:** open any file in the `png` folder.
- **Edit in draw.io:** go to https://app.diagrams.net, choose *Open Existing Diagram* (or *File → Open from → Device*) and select a `.drawio` file. The draw.io desktop app and the draw.io extension for VS Code can also open them.
